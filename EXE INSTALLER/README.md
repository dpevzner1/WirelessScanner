# WirelessScanner — Installer

WirelessScanner is a professional-grade Wi-Fi signal analysis and site survey tool for Windows.

---

## Installation

To comply with GitHub file-size limits, the compiled application is split across multiple `.bin` files.
The Setup wizard reassembles and installs everything automatically.

### Steps

1. Download **all files** in this folder into the **same local directory**.
2. Right-click `WirelessScanner.Setup.exe` → **Run as Administrator**.
3. Follow the wizard:
   - Choose install directory (default: `C:\Program Files\WirelessScanner`)
   - Choose Desktop / Start Menu shortcuts
   - Click **Install**
4. Click **Finish** to launch.

## Updating

Re-run `WirelessScanner.Setup.exe` — detects existing install and offers Update/Reinstall.

## Uninstalling

Re-run `WirelessScanner.Setup.exe` and choose **Uninstall**, or use **Windows Settings → Apps → WirelessScanner**.
