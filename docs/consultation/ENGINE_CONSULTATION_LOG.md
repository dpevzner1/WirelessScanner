# DevOps engine consultation log

The DevOpsAgent knowledge engine (`C:\Users\demit\Documents\Antigrav\DevOpsAgent`) is a **read-only consultation resource** for this project. The protocol is in `docs/PROJECT_CONVENTIONS.md` §5. Each consultation records what was asked, what the engine returned, how it was used and its limits. Raw query output is kept under `governance/evidence/consultation/`.

**Standing limits.** The engine's `query` command searches a keyword and concept index (`corpus_index.json`), and its domain briefs live in `GPT OUTPUT/`. A hit shows that a source discusses a term. It does not establish expert competence; the engine's own `AGENTS.md` and README say so. Recommendations below are the implementer's synthesis, cited to the sources that informed them.
