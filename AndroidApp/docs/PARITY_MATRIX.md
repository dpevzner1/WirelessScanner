# Android parity matrix: Windows 1.5.0 → Android

This matrix checks the owner's requirement: *"ensure all features one for one are ported over"* ([DR-0015](../../docs/decisions/DR-0015-android-port.md)).

- **Row IDs.** Every row reuses the ID of the Windows checklist ([`docs/PARITY_CHECKLIST.md`](../../docs/PARITY_CHECKLIST.md)). Rows added for 1.4/1.5 features without a checklist ID use the prefixes U (physical units), N (connection test), H (history), X (exports), A (REST API and settings) and D (demo and diagnostics).
- **Proof.** Each row gets one of the following:
  - **JVM** — a `core` unit test;
  - **FIX** — a parity fixture generated by the C# code and checked in Kotlin;
  - **EMU** — an emulator render or instrumented test;
  - **DEV** — an owner check on the tablet.
- **Done means proven.** A row is done only with proof (A-LRN-012 / 041).
- **Status.** Statuses are *Planned*, *Built*, *Validated* and *Platform limit*. A platform limit is stated in the app (A-LRN: report capability asymmetry, not false parity).
